# Campus Resource Autopilot — Screenshots Directory

This directory is reserved for user interface screenshots of the running platform.

## Recommended Screenshots

When capturing screenshots from the running web interface (available at `http://localhost:5173`), name and place them here:

1. `dashboard.png` — Main executive overview showing primary metric cards and high-level campus telemetry.
2. `resource-analysis.png` — 7-day and 30-day historical consumption breakdown by resource (Electricity, Water, Waste).
3. `anomaly-detection.png` — Unsupervised Isolation Forest anomaly alerts list with outlier scores.
4. `recommendations.png` — Autopilot Insights cards with root-cause explanations and prioritized facility directives.
5. `impact-measurement.png` — Before/After baseline comparison, simulation controls, and verified savings summary.

> [!NOTE]
> Per project guidelines, no placeholder or fabricated image files are committed. Screenshots can be added by developers or operators after running the frontend and backend locally.
